### Relic — an agent that refactors legacy Python, and refuses when it cannot prove the change is safe

[![ci](https://github.com/rafeyy-sxk/relic-ai/actions/workflows/ci.yml/badge.svg)](https://github.com/rafeyy-sxk/relic-ai/actions/workflows/ci.yml)
![tests](https://img.shields.io/badge/tests-330-brightgreen)
![coverage](https://img.shields.io/badge/coverage-95%25-brightgreen)
![mypy](https://img.shields.io/badge/mypy-strict-blue)

Point it at a repository and walk away. It ranks the files worth its attention,
writes a characterization test suite for each, then **sabotages the original code
twelve times and demands the tests notice.** A suite that catches nothing is
decoration, so that file is left alone and the reason is written down. What
survives gets refactored, verified, and opened as one branch per file.

It also scores every model it can drive over the same corpus and switches off the
ones that stop earning their place.
